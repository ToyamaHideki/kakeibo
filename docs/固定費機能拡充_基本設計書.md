# 固定費機能拡充 基本設計書

- 対象バージョン：**Ver 1.0600（先行リリース）**
- 詳細設計書：`docs/固定費機能拡充_詳細設計書.md`
- 備考：PC版ダッシュボード（別ブランチ `feature/pc-dashboard`）も 1.0600 を確保済み。本機能を先に本番リリースする場合、**ダッシュボード側は復帰時に 1.0700 へ繰り上げる**こと（version.ts / package.json はコンフリクトするためダッシュボード側を上書きで解消）。

---

## 1. 目的

サブスク・保険・ローンといった「契約（Contract）」も毎月/毎年の固定的な支出であるため、固定費一覧（カレンダー＋リスト）に集約表示して、家計の固定支出を一画面で俯瞰できるようにする。あわせて、契約に「個人/共有」の区分を新設し、共有のものを固定費一覧に表示。拡張のため「個人契約も固定費一覧に表示するか」をユーザーが設定で選べるようにする。

---

## 2. スコープ

### 2.1 対象

| # | 内容 |
|---|---|
| 1 | 契約（サブスク/保険/ローン/その他）を固定費一覧に**参照表示**（カレンダー＋リスト） |
| 2 | 契約に **個人/共有（scope）** 区分を新設（全契約タイプ対象） |
| 3 | 固定費一覧には **共有契約**を常時表示。設定ONで**自分の個人契約**も追加表示 |
| 4 | ナビ再編：「サブスク管理」「保険・ローン管理」を **生活管理 → 家計管理** へ移動（Sidebar / BottomNav） |
| 5 | 設定に「個人の契約も固定費一覧に表示する」トグルを新設（ユーザー単位） |

### 2.2 非対象

- 固定費（FixedCost）自体の構造変更（**据え置き。常に世帯共有扱い**）
- 固定費一覧からの契約の編集・追加・削除（**参照のみ**。編集は従来のサブスク管理／保険・ローン管理ページで行う）
- `renewalDate`（次回更新日）未設定の契約のカレンダー表示（**対象外＝一覧に出さない**）
- 個人契約の Firestore レベルでの不可視化（後述リスク参照）

---

## 3. データ方針（個人/共有）

- 既存の「個人=`users/{uid}/`／共有=`households/{id}/`」分離方針に対し、本機能では**実装簡素化を優先**し、契約は引き続き **すべて `households/{id}/contracts`** に保存する。
- 各契約に `scope: 'shared' | 'personal'` と `owner?: string`(uid) を追加。
  - `shared`：世帯の共有契約（owner 不問）
  - `personal`：個人契約。`owner` に作成者 uid を保持
- **固定費（FixedCost）は変更なし**（常に共有）。

## 4. ナビ再編

| 項目 | 変更前 | 変更後 |
|---|---|---|
| サブスク管理（`/subscriptions`） | 生活管理 | **家計管理** |
| 保険・ローン管理（`/contracts`） | 生活管理 | **家計管理** |

- Sidebar（デスクトップ）：家計管理グループ内に追加（固定費一覧の近く）。生活管理からは削除。
- BottomNav（モバイル）：`kakeibo` カテゴリの subPages に追加、`lifestyle` から削除。`activeCategory` の判定も `/subscriptions`・`/contracts` を `kakeibo` に変更。
- ルート定義（`App.tsx`）は変更不要（パスは同じ、グルーピングのみ変更）。

## 5. データ構造

### 5.1 型変更（`src/types/index.ts`）

```typescript
export type ContractScope = 'shared' | 'personal'

export interface Contract {
  // 既存フィールドは維持
  ...
  scope?: ContractScope   // 省略時は 'shared' として扱う（既存データ互換）
  owner?: string          // scope==='personal' のとき作成者 uid
}
```

- 既存契約は `scope` 未設定 → **共有として扱う**（後方互換）。

### 5.2 Firestore

- パス変更なし（`households/{id}/contracts`）。フィールド追加のみ。
- `fixedCosts` は変更なし。

### 5.3 Firestore Rules

- 既存ルール範囲内（フィールド追加のみ）。**変更不要**。
- 留意：個人契約も `households` 配下のため、ルール上は**世帯メンバー全員が読める**。UI で出し分けるのみ（後述リスク）。

### 5.4 設定の保存（個人表示トグル）

- ユーザー単位の表示設定のため **localStorage** に保存（ダッシュボード初期表示設定と同方式。Firestore スキーマ変更なし）。
- キー：`showPersonalInFixedCosts`（`'true'`/`'false'`、既定 false）

## 6. 集約・カレンダー反映ロジック

### 6.1 固定費一覧に表示する要素

```
表示要素 =
    FixedCost（全件・従来どおり、編集可）
  + Contract(scope==='shared' かつ renewalDate あり)（参照のみ）
  + 設定ON時: Contract(scope==='personal' かつ owner===自分 かつ renewalDate あり)（参照のみ）
```

### 6.2 契約 → カレンダー位置の導出（renewalDate ベース）

```
day   = renewalDate の「日」部分（例: 2026-03-27 → 27）
month = renewalDate の「月」部分（yearly のときのみ使用）

frequency:
  monthly → 毎月 day 日に表示
  yearly  → renewalDate の month 月の day 日にのみ表示

土日の振替（getEffectiveDay）は固定費と同じく適用する。
```

- 契約は変動費の概念なし（amount は確定）→ 月次合計に常に加算。
- `renewalDate` 未設定の契約は固定費一覧には出さない（各管理ページには従来どおり表示）。

### 6.3 月次合計

```
当月の固定費合計 =
    Σ FixedCost(当月適用・非変動).amount
  + Σ 表示対象Contract(当月適用).amount
変動（金額未確定）件数 = 従来どおり FixedCost の isVariable のみ
```

## 7. 画面構成（固定費一覧）

### 7.1 カレンダー
- 固定費と契約を**同じ日セルに混在**表示。区別のため契約には種別バッジ（サブスク/保険/ローン/その他）を付す。個人契約には「個人」表示。

### 7.2 リスト（デスクトップ右カラム / モバイル日別モーダル）
- 固定費：従来どおり（編集・削除・並べ替え可）
- 契約：**参照のみ**セクション（編集/削除/ハンドルなし）。行タップは無効、または各管理ページへの導線（詳細設計で確定）。

### 7.3 区別表示
- 種別バッジ：サブスク/保険/ローン/その他
- scope バッジ：個人契約に「個人」（共有は無表示）

---

## 8. 設定画面

「表示設定」に項目を追加：

```
固定費一覧の表示
[ ] 個人の契約も固定費一覧に表示する
    （オフのときは共有の契約のみ表示します）
```

- localStorage 連動（即時反映）。ゲストでも操作可（端末内設定）。

---

## 9. 表示条件・分岐

| 状況 | 振る舞い |
|---|---|
| 契約に renewalDate 未設定 | 固定費一覧に出さない（管理ページには表示） |
| 契約 scope 未設定（既存データ） | 共有として表示 |
| 設定OFF | 共有契約のみ表示 |
| 設定ON | 共有契約＋自分の個人契約を表示（他人の個人契約は出さない） |
| 月次合計 | 表示対象の契約 amount を加算 |
| ゲストモード | 既存の契約データ（共有）で動作。個人契約・設定もセッション内で動作 |

## 10. 非機能・リスク

| リスク | 対応 |
|---|---|
| 個人契約が Firestore 上は世帯メンバーから読める | 仕様（実装簡素化のため households 配下に保存と決定）。UI でのみ出し分け。将来 `users/{uid}/` 分離も可能な設計余地を残す |
| renewalDate 未設定の既存サブスクが一覧に出ない | 仕様。必要なら更新日入力を促す（詳細設計で注記）。将来 startDate 等のフォールバック追加余地 |
| カレンダーに項目が増えて過密 | 種別バッジで区別。1日に複数は既存の集約表示で対応 |
| 月次合計に契約が入り、従来の固定費のみ合計と数値が変わる | 仕様（拡充の目的）。お知らせで周知 |
| 編集導線の誤認（一覧で契約を編集したくなる） | 参照のみと明示。各管理ページへの導線で誘導 |
