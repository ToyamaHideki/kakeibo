# 月別収支リスト 表示モード切替＆合計表示 詳細設計書

- 対象バージョン：**Ver 1.0100**
- 基本設計書：`docs/月別収支リスト表示モード切替_基本設計書.md`
- 想定実装者：下位モデル（Sonnet/Haiku）

---

## ⚠ 実装担当者への注意（必読）

1. **`useHousehold` には setter を新規追加しない**。既存パターン（payDay）と同じく、Context に値のみ追加し、更新は `updateHouseholdSettings()` ＋ `reloadHousehold()` の組み合わせで行う。
2. **`updateHouseholdSettings()` の引数型を Partial 化する**。既存呼び出し `updateHouseholdSettings(id, { payDay })` が壊れないよう、Partial で受けるが両フィールドとも optional にする。型変更時の既存呼び出し箇所は HouseholdSettingsPage.tsx だけのはず（要 grep 確認）。
3. **リスト画面のローカル state**：歯車押下時の楽観的更新のため、`MonthlyPage` / `PersonalPage` で `useHousehold` 値を初期値にしたローカル state を持つ。`useEffect` で Context 値が変わったらローカル state を追随させる（世帯設定画面から変更されたケースに対応）。
4. **ゲストモード**：`isGuest === true` の場合は Firestore 書き込みをスキップ。ローカル state 切替のみで完結させる。
5. **テスト**：既存 `src/test/TransactionList.test.tsx` は `displayMode` 必須化により壊れる。新規 props を必須にする前に、デフォルト引数 or テスト側で props 渡しを追加するかを実装時に判断。**本設計書では Props 必須化** を推奨（型で強制した方が安全）。
6. **lint 警告 0 厳守**：`any` 禁止、未使用 import 禁止、`console.log` 残さない。
7. **コード変更後は必ず**：`npm run lint && npx tsc -b && npm test` の 3 つを順に通すこと。

## 2. `useHousehold` の拡張

### `src/hooks/useHousehold.ts`

```typescript
import { createElement, createContext, useContext, useEffect, useMemo, useState, type ReactNode } from 'react'
import { onAuthStateChanged } from 'firebase/auth'
import type { User } from 'firebase/auth'
import { auth } from '../firebase/firebase'
import { fetchUserProfile, fetchHousehold } from '../firebase/householdFirestore'
import { GUEST_HOUSEHOLD_ID, initGuestStore } from '../firebase/guestStore'
import { buildGuestData } from '../data/guestData'
import type { TransactionListDisplayMode } from '../types'

export type HouseholdState = 'loading' | 'unauthenticated' | 'needs_setup' | 'ready' | 'error'

interface HouseholdContextValue {
  user: User | null
  householdId: string | null
  state: HouseholdState
  payDay: number | null
  transactionListDisplayMode: TransactionListDisplayMode  // 追加
  isGuest: boolean
  reloadHousehold: () => Promise<void>
}

const HouseholdContext = createContext<HouseholdContextValue>({
  user: null,
  householdId: null,
  state: 'loading',
  payDay: null,
  transactionListDisplayMode: 'date',  // 追加（デフォルト）
  isGuest: false,
  reloadHousehold: async () => {},
})

export function HouseholdProvider({ children }: { children: ReactNode }) {
  const [user, setUser] = useState<User | null>(null)
  const [householdId, setHouseholdId] = useState<string | null>(null)
  const [state, setState] = useState<HouseholdState>('loading')
  const [payDay, setPayDay] = useState<number | null>(null)
  const [transactionListDisplayMode, setTransactionListDisplayMode] =
    useState<TransactionListDisplayMode>('date')  // 追加

  async function loadHousehold(firebaseUser: User) {
    try {
      const profile = await fetchUserProfile(firebaseUser.uid)
      if (profile?.householdId) {
        setHouseholdId(profile.householdId)
        const household = await fetchHousehold(profile.householdId)
        setPayDay(household?.payDay ?? null)
        setTransactionListDisplayMode(household?.transactionListDisplayMode ?? 'date')  // 追加
        setState('ready')
      } else {
        setHouseholdId(null)
        setPayDay(null)
        setTransactionListDisplayMode('date')  // 追加
        setState('needs_setup')
      }
    } catch (err) {
      console.warn('[useHousehold] loadHousehold failed:', err)
      setHouseholdId(null)
      setPayDay(null)
      setTransactionListDisplayMode('date')  // 追加
      setState('error')
    }
  }

  async function reloadHousehold() {
    if (user) await loadHousehold(user)
  }

  useEffect(() => {
    function handleGuestMode() {
      initGuestStore(buildGuestData())
      setHouseholdId(GUEST_HOUSEHOLD_ID)
      setPayDay(null)
      setTransactionListDisplayMode('date')  // 追加
      setState('ready')
    }
    window.addEventListener('kakeibo:guest-mode', handleGuestMode)
    return () => window.removeEventListener('kakeibo:guest-mode', handleGuestMode)
  }, [])

  useEffect(() => {
    const unsubscribe = onAuthStateChanged(auth, async firebaseUser => {
      setUser(firebaseUser)
      if (firebaseUser) {
        await loadHousehold(firebaseUser)
      } else {
        setHouseholdId(null)
        setPayDay(null)
        setTransactionListDisplayMode('date')  // 追加
        setState('unauthenticated')
      }
    })
    return unsubscribe
  }, [])

  const isGuest = householdId === GUEST_HOUSEHOLD_ID

  const value = useMemo(
    () => ({ user, householdId, state, payDay, transactionListDisplayMode, isGuest, reloadHousehold }),
    [user, householdId, state, payDay, transactionListDisplayMode, isGuest], // eslint-disable-line react-hooks/exhaustive-deps
  )

  return createElement(HouseholdContext.Provider, { value }, children)
}

export function useHousehold() {
  return useContext(HouseholdContext)
}
```

## 3. `TransactionList` のリファクタ

### `src/features/TransactionList.tsx` 全文（実装版）

```typescript
import { useMemo } from 'react'
import { deleteTransaction } from '../firebase/firestore'
import { useHousehold } from '../hooks/useHousehold'
import { useConfirm } from '../hooks/useConfirm'
import ConfirmDialog from '../components/ConfirmDialog'
import type { Category, PaymentMethod, Transaction, TransactionListDisplayMode } from '../types'

interface Props {
  transactions: Transaction[]
  categories: Category[]
  paymentMethods: PaymentMethod[]
  onEdit: (transaction: Transaction) => void
  onDeleted: () => void
  onDelete?: (yearMonth: string, transactionId: string) => Promise<void>
  displayMode: TransactionListDisplayMode
  onToggleDisplayMode: () => void
}

const WEEKDAYS = ['日', '月', '火', '水', '木', '金', '土']

function formatDateLabel(dateStr: string): string {
  const parts = dateStr.split('-').map(Number)
  const year = parts[0]!
  const month = parts[1]!
  const day = parts[2]!
  const date = new Date(year, month - 1, day)
  return `${month}月${day}日（${WEEKDAYS[date.getDay()]}）`
}

function formatShortDate(dateStr: string): string {
  const parts = dateStr.split('-').map(Number)
  return `${parts[1]}/${parts[2]}`
}

interface GroupSummary {
  income: number
  expense: number
}

function summarize(transactions: Transaction[]): GroupSummary {
  return transactions.reduce<GroupSummary>(
    (acc, t) => {
      if (t.type === 'income') acc.income += t.amount
      else acc.expense += t.amount
      return acc
    },
    { income: 0, expense: 0 },
  )
}

function SummaryAmount({ summary }: { summary: GroupSummary }) {
  const hasIncome = summary.income > 0
  const hasExpense = summary.expense > 0
  return (
    <span className="text-xs font-semibold tabular-nums shrink-0">
      {hasIncome && (
        <span className="text-sage-600">+¥{summary.income.toLocaleString()}</span>
      )}
      {hasIncome && hasExpense && <span className="text-gray-300 mx-1">/</span>}
      {hasExpense && (
        <span className="text-terracotta-500">-¥{summary.expense.toLocaleString()}</span>
      )}
    </span>
  )
}

interface Group {
  key: string
  label: string
  color: string | null  // カテゴリ別モード時のアクセントカラー
  items: Transaction[]
  summary: GroupSummary
}

function groupByDate(transactions: Transaction[]): Group[] {
  const map = new Map<string, Transaction[]>()
  for (const t of transactions) {
    const list = map.get(t.date) ?? []
    list.push(t)
    map.set(t.date, list)
  }
  const groups: Group[] = []
  for (const [date, items] of map) {
    groups.push({
      key: date,
      label: formatDateLabel(date),
      color: null,
      items,
      summary: summarize(items),
    })
  }
  // 日付降順
  groups.sort((a, b) => b.key.localeCompare(a.key))
  return groups
}

function groupByCategory(
  transactions: Transaction[],
  categoryMap: Map<string, Category>,
): Group[] {
  const map = new Map<string, Transaction[]>()
  for (const t of transactions) {
    const key = categoryMap.has(t.categoryId) ? t.categoryId : '__unknown__'
    const list = map.get(key) ?? []
    list.push(t)
    map.set(key, list)
  }
  const groups: Group[] = []
  for (const [categoryId, items] of map) {
    // カテゴリ内は日付降順
    const sorted = [...items].sort((a, b) => b.date.localeCompare(a.date))
    const summary = summarize(sorted)
    const category = categoryMap.get(categoryId)
    groups.push({
      key: categoryId,
      label: category?.name ?? '（不明）',
      color: category?.color ?? null,
      items: sorted,
      summary,
    })
  }
  // 合計絶対値（income + expense）の降順、不明は末尾
  groups.sort((a, b) => {
    if (a.key === '__unknown__') return 1
    if (b.key === '__unknown__') return -1
    const aTotal = a.summary.income + a.summary.expense
    const bTotal = b.summary.income + b.summary.expense
    return bTotal - aTotal
  })
  return groups
}

export default function TransactionList({
  transactions,
  categories,
  paymentMethods,
  onEdit,
  onDeleted,
  onDelete,
  displayMode,
  onToggleDisplayMode,
}: Props) {
  const { householdId } = useHousehold()
  const { confirm, dialogProps } = useConfirm()
  const categoryMap = useMemo(() => new Map(categories.map(c => [c.id, c])), [categories])
  const paymentMethodMap = useMemo(
    () => new Map(paymentMethods.map(pm => [pm.id, pm])),
    [paymentMethods],
  )

  const groups = useMemo<Group[]>(() => {
    if (displayMode === 'category') return groupByCategory(transactions, categoryMap)
    return groupByDate(transactions)
  }, [transactions, displayMode, categoryMap])

  async function handleDelete(transaction: Transaction) {
    if (!await confirm('この収支を削除しますか？')) return
    const ym = transaction.date.slice(0, 7)
    const deleteFn = onDelete ?? ((ym: string, tid: string) => deleteTransaction(householdId!, ym, tid))
    await deleteFn(ym, transaction.id)
    onDeleted()
  }

  const modeLabel = displayMode === 'date' ? '日付別' : 'カテゴリ別'
  const nextModeLabel = displayMode === 'date' ? 'カテゴリ別' : '日付別'

  return (
    <div className="space-y-3">
      {/* ヘッダーカード（表示モード切替） */}
      <div className="bg-white rounded-xl shadow-sm border border-gray-100 px-4 py-2 flex items-center justify-between">
        <span className="text-xs font-semibold text-gray-600">{modeLabel}</span>
        <button
          onClick={onToggleDisplayMode}
          aria-label={`表示モード切替（${nextModeLabel}へ）`}
          title={`${nextModeLabel}に切り替え`}
          className="p-1 text-gray-400 hover:text-sage-600 rounded transition-colors"
        >
          <svg className="w-4 h-4" viewBox="0 0 24 24" fill="none" stroke="currentColor" strokeWidth="2">
            <circle cx="12" cy="12" r="3" />
            <path d="M19.4 15a1.65 1.65 0 00.33 1.82l.06.06a2 2 0 010 2.83 2 2 0 01-2.83 0l-.06-.06a1.65 1.65 0 00-1.82-.33 1.65 1.65 0 00-1 1.51V21a2 2 0 01-2 2 2 2 0 01-2-2v-.09A1.65 1.65 0 009 19.4a1.65 1.65 0 00-1.82.33l-.06.06a2 2 0 01-2.83 0 2 2 0 010-2.83l.06-.06A1.65 1.65 0 004.68 15a1.65 1.65 0 00-1.51-1H3a2 2 0 01-2-2 2 2 0 012-2h.09A1.65 1.65 0 004.6 9a1.65 1.65 0 00-.33-1.82l-.06-.06a2 2 0 010-2.83 2 2 0 012.83 0l.06.06A1.65 1.65 0 009 4.68a1.65 1.65 0 001-1.51V3a2 2 0 012-2 2 2 0 012 2v.09a1.65 1.65 0 001 1.51 1.65 1.65 0 001.82-.33l.06-.06a2 2 0 012.83 0 2 2 0 010 2.83l-.06.06A1.65 1.65 0 0019.4 9a1.65 1.65 0 001.51 1H21a2 2 0 012 2 2 2 0 01-2 2h-.09a1.65 1.65 0 00-1.51 1z" />
          </svg>
        </button>
      </div>

      {transactions.length === 0 ? (
        <div className="bg-white rounded-xl border border-gray-100 shadow-sm p-10 text-center">
          <p className="text-gray-500 text-sm">収支データがありません</p>
          <p className="text-gray-500 text-xs mt-1">＋ボタンから収支を登録してください</p>
        </div>
      ) : (
        groups.map(group => (
          <div
            key={group.key}
            className="bg-white rounded-xl shadow-sm border border-gray-100 overflow-hidden"
          >
            <div className="px-4 py-2 bg-gray-50 border-b border-gray-100 flex items-center justify-between gap-2">
              <span className="text-xs font-semibold text-gray-500 truncate">
                {group.color && (
                  <span
                    className="inline-block w-2 h-2 rounded-full mr-1.5 align-middle"
                    style={{ backgroundColor: group.color }}
                  />
                )}
                {group.label}
              </span>
              <SummaryAmount summary={group.summary} />
            </div>

            {group.items.map((t, idx) => {
              const category = categoryMap.get(t.categoryId)
              const paymentMethod = t.paymentMethodId ? paymentMethodMap.get(t.paymentMethodId) : undefined
              const showCategoryInRow = displayMode === 'date'
              return (
                <div
                  key={t.id}
                  className={`flex items-center px-4 py-3 gap-3 ${
                    idx < group.items.length - 1 ? 'border-b border-gray-50' : ''
                  }`}
                >
                  <div
                    className="w-1 h-8 rounded-full shrink-0"
                    style={{ backgroundColor: category?.color ?? '#9ca3af' }}
                  />
                  <div className="flex-1 min-w-0">
                    {showCategoryInRow ? (
                      <p className="text-sm font-medium text-gray-700">{category?.name ?? '不明'}</p>
                    ) : (
                      <p className="text-sm font-medium text-gray-700">{formatShortDate(t.date)}</p>
                    )}
                    {paymentMethod && (
                      <p className="text-xs text-gray-500 truncate mt-0.5">{paymentMethod.name}</p>
                    )}
                    {t.memo && (
                      <p className="text-xs text-gray-500 truncate mt-0.5">{t.memo}</p>
                    )}
                  </div>
                  <span
                    className={`text-base font-bold tabular-nums shrink-0 ${
                      t.type === 'income' ? 'text-sage-600' : 'text-terracotta-500'
                    }`}
                  >
                    {t.type === 'income' ? '+' : '-'}¥{t.amount.toLocaleString()}
                  </span>
                  <div className="flex items-center gap-0.5 shrink-0">
                    <button
                      onClick={() => onEdit(t)}
                      aria-label="編集"
                      className="p-1.5 text-gray-300 hover:text-sage-500 rounded transition-colors"
                    >
                      <svg className="w-4 h-4" viewBox="0 0 24 24" fill="none" stroke="currentColor" strokeWidth="2">

                        <path d="M18.5 2.5a2.121 2.121 0 0 1 3 3L12 15l-4 1 1-4 9.5-9.5z" />

                      </svg>
                    </button>
                  </div>
                </div>
              )
            })}
          </div>
        ))
      )}
      <ConfirmDialog {...dialogProps} />
    </div>
  )
}
```

## 10. 補足

### 10.1 既存呼び出し箇所の確認用 grep

実装前に以下を確認しておくと安全：

```
grep -rn "updateHouseholdSettings" src/
grep -rn "useHousehold()" src/
```

`useHousehold()` を destructure している箇所は payDay 利用箇所が中心。`transactionListDisplayMode` を取り出すのは MonthlyPage / PersonalPage / HouseholdSettingsPage の 3 箇所のみ。他の箇所には触れない。

### 10.2 楽観的更新の代替案（採用しない）

リスト画面で `useHousehold` 値を直接使い、ローカル state を持たない案も考えられるが、`reloadHousehold()` が完了するまでラグがある（fetchHousehold の往復）。歯車押下から表示変更まで 200〜500ms 程度遅延するので、ローカル state による楽観的更新を採用した。

### 10.3 ゲストモード

`isGuest === true` の場合は Firestore に書き込まない。ローカル state のみで切替が動作する。ページ遷移・リロード時にはデフォルトに戻るが、ゲストは一時利用前提なので許容する。
