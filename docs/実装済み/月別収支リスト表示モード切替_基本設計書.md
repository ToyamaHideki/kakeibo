# 月別収支リスト 表示モード切替＆合計表示 基本設計書

- 対象バージョン：**Ver 1.0100**
- 関連プラン：`C:\Users\toyam\.claude\plans\3-ver-1-0000-bubbly-spring.md`
- 詳細設計書：`docs/月別収支リスト表示モード切替_詳細設計書.md`

---

## 1. 目的

月別収支リストは現状「日付降順」のみで表示される。これだと「今月どのカテゴリにいくら使ったか」が一目で分からず、ユーザーは頭で集計するか別画面（年間収支など）に遷移する必要がある。

本機能では以下の 2 つの体験を提供する：

1. **表示モード切替**：日付別 ↔ カテゴリ別をワンタップで切替
2. **合計金額表示**：各グループヘッダーに収入/支出合計を表示し、内訳を即座に把握可能にする

合わせて、表示モードを世帯設定として永続化することで、メンバー間で表示の前提を統一する。

---

## 2. スコープ

| 機能 | 対象画面 | 永続化 |
|---|---|---|
| 表示モード切替（歯車アイコン） | MonthlyPage / PersonalPage | households ドキュメント |
| グループヘッダー合計表示 | TransactionList（両画面共通） | — |
| 表示モードのデフォルト設定 | HouseholdSettingsPage | households ドキュメント |

非対象：
- 年間収支・予算管理・固定費一覧などのリスト：対象外
- グルーピング基準としての「支払い方法別」「タイプ別（収入/支出）」：今回は不要

## 4. データフロー

### 4.1 読み込み

```
useHousehold (Provider)
    │
    ├─ fetchHousehold(householdId)
    │      └→ household.transactionListDisplayMode
    │
    ├─ Context 値： transactionListDisplayMode: 'date' | 'category'
    │              （未設定の場合は 'date' を fallback）
    │
    └→ MonthlyPage / PersonalPage / TransactionList が consume
```

### 4.2 切替（リスト画面の歯車押下）

```
ユーザー：歯車押下
   │
   ├─ MonthlyPage 内：useState ローカル state を即時反転
   │   └→ TransactionList 再レンダ（即時反映）
   │
   └─ 並行： updateHouseholdSettings(householdId, { transactionListDisplayMode }) (Firestore)
       └→ 完了後 reloadHousehold() で Context 同期
```

### 4.3 切替（世帯設定画面の保存ボタン）

```
ユーザー：ラジオ選択 → 保存押下
   │
   └─ updateHouseholdSettings(householdId, { transactionListDisplayMode })
       └→ reloadHousehold()
           └→ Context 同期 → 全画面に反映
```

## 5. データ構造

### 5.1 Firestore：`households/{householdId}` への追加

| フィールド | 型 | 値 | 必須 |
|---|---|---|---|
| `transactionListDisplayMode` | `'date' \| 'category'` | デフォルト `'date'` | 任意（未設定時は `'date'` 扱い） |

既存利用者は未設定状態 → アプリ側で fallback して 'date' で表示。マイグレーション不要。

### 5.2 Firestore Rules

変更不要。`households/{id}` ドキュメントへのフィールド追加のみで、既存 rule（メンバーは r/w 可）の範囲内。

## 6. 表示条件

### 6.1 グループヘッダー合計

| モード | グルーピング | 合計値 | 表示形式 |
|---|---|---|---|
| 日付別 | `transaction.date` | 同日の収入合計 / 支出合計 | 両方ある日：`+¥X / -¥Y`、片方のみ：その種別のみ |
| カテゴリ別 | `transaction.categoryId` | カテゴリ全件の合計 | 同上（混在カテゴリは両方表示） |

カラー：
- 収入：`text-sage-600`
- 支出：`text-terracotta-500`
- `tabular-nums` で桁ぞろえ

### 6.2 カテゴリ別モードのソート

- グループ間：**合計金額の絶対値降順**（よく使うカテゴリが上）
- 同一グループ内：**日付降順**（最新が上）
- 未知カテゴリ（categoryMap に無い）：末尾に「（不明）」として集約

### 6.3 ヘッダーカード（切替UI）の表示

- transactions が 0 件の場合でも表示する（切替自体は可能にしておく）
- ただし「収支データがありません」カードは従来通り表示

## 7. 非機能要件

### 7.1 パフォーマンス
- グルーピング処理は `useMemo` で `displayMode` と `transactions` 変化時のみ再計算
- 1 ヶ月分の transactions は最大数百件想定 → 単純な reduce で十分（O(N)）

### 7.2 永続化
- 表示モード設定は世帯単位（payDay と同じ）。複数メンバーで同じ前提が共有される
- 楽観的更新：UI は即時反映、Firestore 更新は背景で並行

### 7.3 アクセシビリティ
- 歯車ボタン：`aria-label="表示モード切替"`
- ラジオボタンは標準の `<input type="radio">` で実装

### 7.4 デザイン一貫性
- ヘッダーカードは既存カードスタイル（`bg-white rounded-xl shadow-sm border border-gray-100`）踏襲
- 歯車アイコンは SVG（24x24, strokeWidth=2、stroke-currentColor）。Sidebar/設定アイコンと同じトーン

## 8. 既知リスク・考慮事項

| リスク | 対応 |
|---|---|
| 既存ユーザーの households ドキュメントに `transactionListDisplayMode` フィールドがない | `?? 'date'` で fallback。マイグレーション不要 |
| カテゴリ別モードで同一カテゴリに収入/支出混在 | 「+¥X / -¥Y」併記で安全側に倒す |
| 歯車押下中の Firestore 書き込みエラー | UI はローカル即時反映済み、reload 失敗時のみ次回読み込みで Firestore 状態に同期。トースト等は今回省略（payDay と同等の沈黙運用） |
| デスクトップとモバイルで表示が乖離 | ヘッダーカードは両方で表示。md ブレイクポイントでのレイアウトは TransactionList 内部に閉じる |
| ゲストモード（GUEST_HOUSEHOLD_ID） | guestStore に保存しない（リロードでリセットされる）。useState のローカル切替のみで完結する設計にする |
